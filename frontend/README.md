# NVID frontend

Next.js 15 (App Router) · TypeScript · Tailwind v4 · shadcn/ui · Framer Motion · wagmi 2 + RainbowKit 2 · ethers v6.
Full documentation lives in the [root README](../README.md).

```bash
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
npm run build
npm run lint
```

```
app/          layout · page (landing) · rewards/page · providers · globals.css (design tokens)
components/   Hero · VaultRing · LiveStats · HowItWorks · RewardsDashboard · Tokenomics · FeeDonut
              Navbar · Footer · WalletButton · motion (fade-up / opacity / scale) · ui/* (shadcn)
hooks/        useRewards (reads + claim state machine) · useStats · useMounted
lib/          site · chains · wagmi · contracts (address resolution) · format · data/stats (provider)
lib/abi/      generated by `contracts` on every compile — do not edit
```

Contract addresses resolve from `NEXT_PUBLIC_*` env overrides first, then from `lib/abi/deployments.ts`
by chain id. With neither, the rewards dashboard shows its "not deployed on this network" state and
the stats cards stay on the labelled preview provider.
